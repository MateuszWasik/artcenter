# ArtCenter

Strona https://artcenter.com.pl (Astro 4, statyczna).

```bash
npm install
npm run dev      # serwer deweloperski
npm run build    # wynik w dist/
```

- Zdjęcia strony głównej należy wgrać do `public/images/`: `artcenter_9.jpg`, `artcenter_5.jpg`, `328.jpg`, `artcenter_2.jpg`.
- Style: `src/styles/global.css` (skompilowany CSS Tailwind odzyskany z produkcji).
- Repozytorium odtworzone z plików produkcyjnych (`public_html`).
